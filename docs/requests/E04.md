- Target: coordinator, E01 contract owner and E03 questionnaire owner.
- Status: pending.

  Classification cannot be less restrictive than its dictionary field; private_journal fields are prohibited.
  Require `review_state` and the document notice; rejected/withdrawn definitions are ineligible, while missing
  clinical sign-off is labeled under Part A Q1/Q7/Q18. Extend choices with nullable `module_id` and
  `opens: intake_module`; that action requires `presence: present` and an existing module. Unknown/declined area
  choices have no module/action. Prohibit absent area choices. Add `kind: text` for bounded self-report scalar
  strings, preserving the existing scalar Answer value union; no unconfirmed examination/report becomes a finding.
  Text, scale and duration questions accept unknown/declined with null value and no unit. Choice questions require
  nonnull presence on every choice. Add explicit unknown and declined choices to each example red flag, preserving
  all existing urgent choice/flow mappings. Apply design section 8 checks in both hub and package validators.
- Reason: the closed base schema has no intake routing, sensitivity, applicability or text-question extension.
  Optional metadata and generic question sets cannot deliver R04/R05/E04-02 safely.

  Existing verified fixed help remains available. Preserve identity/origin, red-flag access, consent, sensitivity,
