# E12 requests

Canonical requests for `docs/tdd/E12.md`. Targets name the coordinator and affected owners. Settled entries retain
their identifiers so that the old design's proposals are not mistaken for outstanding permission to change contracts.
Open entries block the affected acceptance, not independent safety functions. SYSTEM.md is abbreviated S.

## R-E12-1: Represent pinned passage citations

- Status: Open.
- Target: Coordinator; product package, E10 and E13 owners.
- Exact proposal: Add a passage-reference variant to the effective evidence reference union used by assistant outputs,
  with passage ID, evidence release ID, permitted use and content hash. Specify the corresponding citation response
  and E13 verifier binding, including the Q1/Q18 clinical-review label. Resolve this together with E10's existing
  citation response requests in `docs/requests/E10.md`; do not create a second retrieval API. Every expanded passage
  must retain its own exact reference, and history must be distinguishable from current eligible support.
- Reason: The current common evidence reference union has no passage variant. The base EvidencePassage response
  cannot represent all effective pin, use and review metadata required by the revised provider. An internal result
  alone cannot satisfy the crew-visible citation acceptance.
- Interim: Keep citation-dependent clinical publication off until the effective wire representation and E13 verifier
  agree. Internal retrieval may be tested, but R16/R21, E12-02, V23/V24 and D10 remain incomplete. Preserve source
  rights, release pinning, purpose, applicability, eligibility and review labeling; never substitute the active release
  or hide the missing citation behind a generic link.

## R-E12-2: Finalize stage catalogs and public search arguments

- Status: Open.
- Target: Coordinator; E17, E13 and product configuration owners.
- Exact proposal: Finalize the pinned tool catalog's closed nested argument/result schemas, per-stage tool sets,
  action-to-tool mapping and proposal-result envelope. Scope, actor, subject, episode, release pins and authorization
  are injected by the controller and absent from model-writable arguments. Define a bounded public-evidence query

  Unbound tools and unsafe free-text search remain unavailable. Preserve closed-schema validation, stage membership,
  injected scope, code/source/body-region checks, bounded parsing, privacy and denial auditing. E12-01, R17 and
  T-E12-001/T-E12-002 remain blocked for unfinished catalog entries; no permissive schema stands in for acceptance.
