# Contract change requests from B2 (chemistry layer)

Each entry gives the exact proposed change, the reason and the interim behavior that the code implements now
(commented in code with the request number). Numbers come from the committed cache and the B2 tests unless stated.
Status: R1 to R24 are decided and implemented as decided (the code no longer points at them).

---

## R1. Spec 7.2: enumerate SMARTS mappings without uniquify

**Proposed change (spec 7.2, first sentence):** replace "run each SMARTS with `GetSubstructMatches` (uniquify true)"
with "run each SMARTS with `GetSubstructMatches(uniquify=False)` (all mappings, RDKit's default `maxMatches` of 1000;
reaching it raises `StructureError`)".

**Reason:** with uniquify true RDKit returns one mapping per atom set. The catechol pattern
`[OX2H1:1][c:2][c][OX2H1]` maps both oxygens of epinephrine as one atom set, so only O10 becomes a catechol site and
O11 falls to `phenol_autoxidation`, which contradicts the expected table in the same section (epinephrine has no
phenol pathway). Enumerating all mappings and collapsing by site atom (first pattern, first match wins) gives
catechol sites (10, 11) and the documented table.

**Interim:** implemented as proposed (`structure.site_matches`).

## R2. Spec 7.5: phenol O-H range is incompatible with the 7.4 procedure

**Proposed change (spec 7.5):** replace "phenol O-H BDE in [300, 420] kJ/mol" with "phenol O-H BDE minus methanol
O-H BDE within 10 kJ/mol of the experimental difference -77.4 kJ/mol (Blanksby and Ellison 2003: 362.8 and 440.2)".
If R11 adopts spin polarization, the absolute range [300, 420] can stay.

**Reason:** spec 7.4 computes electronic GFN2-xTB energies without spin polarization. Its phenol O-H BDE is
468.4 kJ/mol (cache, reproducible). Absolute values sit 97 to 135 kJ/mol above experiment depending on the bond
(phenol 468.4 vs 362.8, methane 574.4 vs 439.3, ethane 544.9 vs 423.0). Differences are close to experiment: phenol minus methanol is -80.9 (experiment -77.4).
Evans-Polanyi only uses differences against a reference computed the same way.

**Interim:** the range test is `xfail(strict=True)` with this reason; the difference test above passes
(`test_bde_xtb.py`).

## R3. Spec 7.3.1 vs 7.3.5: several sites when no series applies

**Proposed change (spec 7.3.1):** append "Each site gets its own delta (0 where no series applies) and the sites
combine by 7.3.5, so an ingredient with n sites against an anchor with n_ref sites and no applicable series gets
ln(n / n_ref)." Also state in 7.3 that the series are those in `computed_method.series_ids`, every applicable series
adds its delta at a site, and the method label is the single kind applied, else the class kind, else `anchor_only`.

**Reason:** 7.3.1 says "the result is delta 0" when the method cannot apply; 7.3.5 says sites combine as
ln(sum exp(delta_s) / n_ref). They disagree whenever the site counts differ. The statistical factor is the physical
reading (two equivalent esters hydrolyze twice as fast). No formulary product is affected today (every
anchor_only case has one site on each side).

**Interim:** per-site deltas combined by 7.3.5 (`lfer.computed_adjustment`).

## R4. Spec 7.3.2: ring of a series whose mapped atom is not aromatic

**Proposed change (spec 7.3.2):** replace "the ring is the aromatic ring containing the atom mapped m" with "the ring
is the smallest aromatic ring containing the atom mapped m, or, when that atom is not aromatic, the ring of its
aromatic neighbor (lowest atom index)".

**Reason:** `hammett_benzoate_alkaline` maps 1, the carbonyl carbon, which is in no ring; its own `reaction` text says
"ring attached to the acyl carbon (map 1)". Read literally the series never applies.

**Interim:** as proposed (`lfer._ring_atom`).

## R5. Spec 7.3.1: which substituents add variance

**Proposed change (spec 7.3.1):** "Substituents identical in fragment and position on the ingredient and anchor rings
cancel. Every remaining ortho or unmatched substituent, on either ring, adds its variance."

**Reason:** the spec does not say whether the anchor's own ortho or unmatched substituents count, nor whether
identical ones cancel. An unmatched group present on both rings at the same position cancels exactly in the
difference, so adding its variance would be wrong.

**Interim:** as proposed (`lfer._residual`, `lfer._hammett_outcome`).

## R6. Spec 7.3.4: Evans-Polanyi when the class has an anchor

**Proposed change (spec 7.3.4):** add "With an anchor, the reference is the anchor molecule: BDE_ref is the anchor's
first site of the class and n_ref its number of sites; the result is a computed-layer delta with the method error."

**Reason:** the spec describes only the anchor-free case (no Evans-Polanyi class has an anchor today). The anchor's
rate belongs to the anchor molecule, so the shift must be taken against it, not against the table's reference.

**Interim:** as proposed (`lfer.computed_adjustment`); it needs the keyword-only arguments of R15.

## R7. Type `ComputedDetail.cache_key` holds one key, Evans-Polanyi uses several

**Proposed change (pharmacy/types.py):** replace `cache_key: str | None` with `cache_keys: tuple[str, ...]` (empty
when no BDE was used).

**Reason:** an Evans-Polanyi shift uses at least two BDEs (site and reference); promethazine's amine pathway uses
three. `Pins.computed_cache_keys` needs all of them.

**Interim:** the keys are sorted and joined with commas in the existing string field; `parameters.computed_cache_keys`
splits them.

## R8. Spec 9.1: several product models match

**Proposed change (spec 9.1, item 1):** append "If several match, a model with a non-null `package_id` wins over a
package-independent one; then config order."

**Reason:** the spec does not choose among several matching models; the package-specific model is the more specific
evidence.

**Interim:** as proposed (`parameters.select_measured_model`).

## R9. Spec 7.4: canonical rank with symmetry classes

**Proposed change (spec 7.4, cache key):** replace "canonical rank of the site atom" with "symmetry-class canonical
rank of the site atom (RDKit `CanonicalRankAtoms(breakTies=False)`); symmetry-equivalent sites share one entry,
computed on the class member that comes first in the canonical SMILES".

**Reason:** with ties broken (RDKit's default) the rank of one of several equivalent atoms depends on how the SMILES
was written. A B2 test that permutes atom order found that promethazine's two N-methyls swap keys, and one conformer
gives them different values (490.30 and 492.11 kJ/mol), so the entry a site receives depended on the spelling.
Symmetry-class ranks are graph invariants (checked on 20 random atom permutations each of promethazine, levofloxacin,
epinephrine and trimethylamine). The rebuilt
cache holds 14 entries; every value is bit-identical to the earlier computation of the same atom.

**Interim:** as proposed (`bde._validate_site`).

## R10. Spec 7.3.4 and 9.5: Evans-Polanyi shifts are unbounded and break the calibrated total (high priority)

**Proposed change (spec 9.5):** replace the Evans-Polanyi paragraph with: "Evans-Polanyi shifts redistribute the
calibrated total among the N split pathways instead of adding to it:
`mu_p,i = mu_total + delta_i - ln(sum_j exp(delta_j))`, with delta_j = 0 for split members without a shift, plus the
independent method-error term as now (s_post^2 = s_p^2 + s_m^2, w = s_p^2 / s_post^2)." Alternatively (smaller change),
add a configured bound `evans_polanyi[].max_abs_delta_bde_kj_per_mol` (team default, for example 30) beyond which the
BDE difference is clamped and the clamping is flagged.

**Reason:** the shift is added to `mu_total - ln N`, so it raises the product's total rate above the Du 2011
calibration by up to the shift. With the spec procedure the formulary gets (ln units, alpha 0.5, T* 298.15 K):

| Product, pathway | BDE site vs reference (kJ/mol) | delta ln k | resulting ln k* (1/s) |
|---|---|---|---|
| amoxicillin, amine_alpha_oxidation (C12) | 376.97 vs 492.88 (trimethylamine) | +22.28 | +0.29 |
| epinephrine, catechol_autoxidation | 457.51, 427.51 vs 463.97 (catechol) | +6.66 | -14.69 |
| levofloxacin, amine_alpha_oxidation | 460.89 (x2), 476.14 vs 492.88 | +6.07 | -14.31 |
| acetaminophen, phenol_autoxidation | 446.88 vs 468.43 (phenol) | +4.35 | -16.73 |
| promethazine, amine_alpha_oxidation | 468.63, 490.30 (x2) vs 492.88 | +3.82 | -17.26 |
| epinephrine, amine_alpha_oxidation | 494.61, 473.17 vs 492.88 | +2.89 | -18.46 |
| amoxicillin, phenol_autoxidation | 461.55 vs 468.43 | +1.39 | -20.60 |

ln k* = +0.29 means a half-life of about half a second for amoxicillin tablets at 25 C, while the configured
amoxicillin capsule anchor (same molecule, 34 months at JSC) gives ln k about -21.6. The C12 site is benzylic, alpha
to the amide carbonyl and alpha to NH2 (a captodative radical), very unlike the trimethylamine reference; a linear
Evans-Polanyi relation is not valid over a 116 kJ/mol gap. The gap is not a method artifact: B2 recomputed the
formulary sites with spin polarization and with spin polarization plus five conformers, and C12 stays 102 to 116
kJ/mol below the reference (study table in R11). Also missing from the formula: the count of abstractable hydrogens
(a CH site vs a CH3 reference).

**Interim:** the spec formula exactly as written (the spec is explicit here, so the code does not invent a bound).
Downstream builders should expect the amoxicillin amine pathway to dominate every amoxicillin forecast until this is
decided.

## R11. Spec 7.4: BDE method (conformers and spin polarization)

**Proposed change (spec 7.4 and engine-settings `computed_layer`):**

1. New setting `xtb_n_conformers` (team default 10): embed that many ETKDGv3 conformers with `rdkit_embed_seed`
   (`EmbedMultipleConfs`), MMFF94 then GFN2-xTB optimize each, take the lowest parent energy; build the radical from
   every optimized parent conformer and take the lowest radical energy.
2. New setting `xtb_spin_polarization` (team default true): add tblite's spin-polarization interaction
   (`Calculator.add("spin-polarization", 1.0)`) for the open-shell radical and the hydrogen atom.
3. Both settings go into the cache key; the cache is regenerated.

**Reason:** a lab would not take one conformer for a flexible molecule, and open-shell xTB energies without spin
polarization put absolute BDEs 97 to 135 kJ/mol too high (R2). B2's scratch study (same seed, kJ/mol):

| Quantity | spec 7.4 | spin polarized | spin polarized, 5 conformers | experiment |
|---|---|---|---|---|
| methane C-H | 574.4 | 443.4 | | 439.3 |
| ethane C-H | 544.9 | 420.5 | | 423.0 |
| toluene benzylic C-H | 472.3 | 364.2 | | 375.3 |
| phenol O-H | 468.4 | 365.2 | | 362.8 |
| methanol O-H | 549.3 | 433.4 | | 440.2 |
| acetaminophen O-H minus phenol | -21.5 | -18.9 | -17.3 | |
| epinephrine O10 minus catechol | -6.5 | -5.9 | -37.8 | |
| epinephrine O11 minus catechol | -36.5 | -35.6 | -30.5 | |
| levofloxacin C19 minus trimethylamine | -36.8 | -33.1 | -14.0 | |
| amoxicillin C12 minus trimethylamine | -115.9 | -102.7 | -101.8 | |

Catechol with ten conformers moves from 464.0 to 431.2 kJ/mol (330.6 spin polarized) because the intramolecularly
hydrogen-bonded radical is only found from some conformers. Single-conformer site values therefore swing by up to
30 kJ/mol (6 ln units) with the conformer, which is larger than the method error the classes assume (1 log10).

**Interim:** the spec procedure (one conformer, no spin polarization).

## R12. Spec 7.4: cache key misses optimizer settings

**Proposed change (spec 7.4, key list):** add `optimizer_gtol_eh_per_bohr` and `optimizer_max_steps` to the cache key.

**Reason:** the converged geometry, hence the BDE, depends on the gradient tolerance. Changing it in engine-settings
would silently return entries computed with the old tolerance.

**Interim:** key exactly as the spec lists it; the method label stored in each entry records the tolerance.

## R13. Spec 7.4: reproducibility needs single-threaded tblite

**Proposed change (spec 7.4, last sentence):** append "tblite's OpenMP and OpenBLAS runtimes run single-threaded
(set by `bde` before the first calculation), because threaded gradient reductions change the last bits and therefore
the optimizer path."

**Reason:** with several threads the energy is reproducible but the gradient is not, and the L-BFGS-B path (and the
BDE) differed between runs. Pinned, all 14 committed entries recompute bit for bit (`test_bde_xtb.py`).

**Interim:** implemented (`bde._pin_tblite_threads`, ctypes calls into the libraries bundled with tblite).

## R16. pyproject: the coverage exclusion `\.\.\.` excludes whole functions (affects every builder)

**Proposed change (pyproject.toml, `[tool.coverage.report] exclude_also`):** replace `"\\.\\.\\."` with
`"^\\s*\\.\\.\\.\\s*$"`.

**Reason:** the unanchored pattern matches `tuple[X, ...]` in annotations. Coverage excludes a matching line, and a
matching `def` line excludes the whole function. `pharmacy/chemistry/pathways.py` reports 12 statements instead of
58; every function returning `tuple[..., ...]` disappears from every builder's coverage number.

**Interim:** B2 reports both numbers. With the anchored pattern (scratch coverage rc) the five fast-gated B2 modules
are at 100% branch coverage.

## R17. Spec 7.3 and config: the ester series never run for the formulary

## R20. Spec 7.4: a conformer whose optimization does not converge

**Proposed change (spec 7.4, after "energy the lowest over them"):** add "A conformer whose parent or radical
optimization does not reach `optimizer_gtol_eh_per_bohr` within `optimizer_max_steps` is left out of that minimum;
`ConvergenceError` is raised only when no parent or no radical converged." Alternative: keep the literal rule and
raise `optimizer_max_steps` (engine-settings) to 1000.

**Reason:** with 10 conformers and 500 steps, three optimizations of the formulary sites stop short: the
promethazine methine radical from conformer 7 (converges at 523 steps), the amoxicillin parent from conformer 1 (533
steps) and the amoxicillin alpha-carbon radical from conformer 7 (503 steps). Read literally, one such conformer
fails the whole BDE, so `build_stability_model` raises for promethazine (tablet and injection) and
amoxicillin. Run to convergence with a 5000-step limit (diagnostic only, config untouched), each of them ends above
the minimum the other conformers give (promethazine radical -55.13933 against -55.13977 Eh; amoxicillin parent
-76.32238 against -76.32930 Eh, its radicals -75.75609 and -75.78685 against -75.76405 and -75.79235 Eh; amoxicillin
radical -75.78688 against -75.79235 Eh). Leaving them out therefore gives the same BDEs as a larger step limit for
every committed entry.

**Interim:** as proposed (`bde._compute`); the method label and the cache key are unchanged.

## R21. Spec 9.5: an Evans-Polanyi class without an anchor outside the total-rate split

**Proposed change (spec 9.5, after the redistribution formula):** add "A class with an Evans-Polanyi entry and no
anchor whose pathway is outside the split (racemization) is a configuration error (`ModelDomainError`)."

**Reason:** 7.3.4 and 9.5 define a shift without an anchor only as a redistribution among split members. The former
additive rule is gone, so a shift outside the split has no meaning. No configured class is affected (the three
entries are destructive thermal classes).

**Interim:** as proposed (`parameters._thermal_ln_k`).

## R22. Spec 9.5: method error of a shifted pathway that is alone in its split

**Proposed change (spec 9.5, after "A shifted pathway also draws an independent method-error term"):** add "unless
the split has one member: then mu_p = mu_total whatever the shift, and the pathway keeps s_p and w = 1."

**Reason:** levofloxacin has one split pathway (`amine_alpha_oxidation`, shift +1.648). The redistribution leaves its
mean at mu_total exactly, but the method error still applies: sd 2.3662 instead of 0.545129 and w = 0.0531, so its
ln k* spread is 4.3 times that of every other single-pathway product although the shift changed nothing. The spread
of the total-rate data, which 9.5 says the shared draw keeps, is lost for this product.

**Interim:** the spec as written (the method error is added); no code comment points here because the code follows
the spec.

## R23. Spec 7.4: what "half" of the radical optimizations is measured against

**Proposed change (spec 7.4, "raised when fewer than half of either converged"):** write "when fewer than half of the
parent optimizations (one per embedded conformer) or fewer than half of the radical optimizations (one per converged
parent) converged".

**Reason:** radicals are optimized only from converged parents, so "half of the radical optimizations" can be read
against the parents that converged or against all conformers. With 10 conformers, 5 converged parents and 3 converged
radicals pass the first reading and fail the second. No committed entry is near either limit: the lowest counts are
9 of 10 parents and 8 of 9 radicals (amoxicillin C12).

**Interim:** the first reading (`bde._enough_converged`). `BdeResult` records `conformers_embedded`,
`parents_converged` and `radicals_converged`, so either rule can be checked from the cache.

## R24. Spec 7.3.4 and 9.5: method error of a pathway with no site inside the domain

**Proposed change (spec 9.5, after "with s_m,j = 0 for unshifted members"):** add "and s_m,j = 0 for a member none of
whose sites lies inside the applicability domain (7.3.4): its shift is only the hydrogen-count term
ln(sum_s n_H,s / sum_r n_H,r), which carries no Evans-Polanyi method error."

**Reason:** amoxicillin's `amine_alpha_oxidation` has one site (C12, BDE 96.1 kJ/mol below trimethylamine), so no
Evans-Polanyi relation is applied and its shift is ln(1/9) = -2.197. It still takes the class method error
s_m = ln 10: s_post = 3.006 and w = 0.033, where s_m = 0 would give 1.979 and w = 0.076. The other free members
change little (its share is 0.017).

**Interim:** as proposed (`lfer.evans_polanyi_prior_shift` sets the method error to 0 when no site is inside the
domain and records `n_sites_in_domain` in the descriptors).
